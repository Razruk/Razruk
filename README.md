# Razruk

Desarrollador de software con experiencia en desarrollo full stack con .NET.

## 🛠️ Stack

![C#](https://skillicons.dev/icons?i=cs,php,dotnet,angular,ts,html,css,git,github&perline=8)

- **Backend:** C#, .NET, VB.NET, APIs REST, PHP
- **Datos:** SQL Server, stored procedures, SSRS
- **Mensajería e integraciones:** RabbitMQ, servicios REST
- **Frontend:** Angular, React, TypeScript

## 💼 En qué trabajo

- Desarrollo de aplicaciones y servicios backend con C# y .NET
- Diseño y consumo de APIs REST
- Integraciones entre sistemas mediante APIs y mensajería (RabbitMQ)
- Diseño de bases de datos y lógica en SQL Server: consultas, stored procedures y optimización
- Reportes con SSRS: diseño, parámetros y distribución
- Desarrollo de componentes reutilizables y librerías en C# (assemblies)
- Procesamiento y generación de archivos XML
- Automatización de procesos y tareas repetitivas
- Interfaces web con Angular y TypeScript
- Mantenimiento y mejora de aplicaciones existentes
- Documentación técnica y trabajo directo con usuarios para entender requerimientos
